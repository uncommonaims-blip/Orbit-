# Orbit: Planetary Conquest

A touch-friendly, gravity-based planetary conquest prototype. Capture planets by dragging from a blue planet to another planet. Each launch sends half the available ships.

## Features
- Six continuously orbiting planets
- Fleet production, capture and basic enemy AI
- Gravitational acceleration from nearby planets
- Touch and mouse drag controls
- Mobile-friendly canvas, orbit guides and spacecraft trails
- Win/loss detection and restart

## Run
Open `index.html` in a browser, or deploy using GitHub Pages. No dependencies or build step.

## Prototype limitations
Simplified gravity, no predictive aiming, no saved progress, no multiplayer. Fleet steering favors its selected destination; physical realism is deliberately secondary to playability.

## Roadmap
Predictive intercepts, adjustable launch sizes, balanced AI, multiple systems, accessibility and sound.
